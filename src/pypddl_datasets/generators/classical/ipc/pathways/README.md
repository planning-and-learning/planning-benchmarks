# pathways (ipc)

Biochemical pathways: choose a limited number of initial substances and apply association, catalysed association and synthesis reactions until, for every goal, one of two target molecules is available.

## Source

- **Domain:** Yannis Dimopoulos, Alfonso Gerevini and Alessandro Saetti, IPC 2006 (Pathways-Propositional)
- **Generator:** pddl-generators `pathways/main.c` (`pathways --seed <s> -R <r> -G <g> -L <l>`) by the same authors, with the reaction database `Pathways-Reactions` / `Pathways-SimpleSubs` (shipped here as `reactions.txt` / `simple_substances.txt`); Python port in `generator.py`
- **Reference tasks:** `data/classical/downward-benchmarks/pathways` (30 tasks, one domain file per task); with `strips_wrapper=True`, `data/classical/autoscale-benchmarks-main/21.11-optimal-strips/pathways` (generated by pddl-generators `pathways/wrapper.py`)

## Parameters

| parameter | meaning | reference range |
|---|---|---|
| `min_reactions` (`-R`) | stop adding substances once this many reactions are reachable | 12–480 |
| `num_goals` (`-G`) | number of disjunctive goals | 1–40 |
| `num_substances` (`-L`) | how many initial substances may be chosen (level objects `l0..lL`) | 3–35 |
| `seed` | random seed | IPC seeds in upstream README |
| `strips_wrapper` | encoding of `pathways/wrapper.py` | IPC: false; Autoscale optimal: true |

## Distribution

### Objects
Every simple substance and complex molecule that occurs in a reachable reaction, typed `simple` / `complex`, except the goal molecules, which are domain constants; levels `l0..l<num_substances>`. Object and reaction order follow the upstream data files.

### Initial state
Simple substances are drawn uniformly without replacement from the 79-entry list (including the dummy `_`) until the reactions reachable (relaxed, fix point) from the drawn set number at least `min_reactions`. The reachability is then recomputed from the drawn set; every reachable reaction becomes an `association-reaction`, `catalyzed-association-reaction` or `synthesis-reaction` fact (775 reactions in the database), every simple substance occurring in them a `(possible s)` fact. `(num-subs l0)` and the chain `(next l<i+1> l<i>)`.

### Goal
`(goal1) … (goal<num_goals>)`. Goal `i` is achieved by a dummy action whose precondition is `(or (available a) (available b))`. The 2·`num_goals` molecules are drawn without replacement from the reachability levels of the second pass: with probability 40 % from the last level, 20 % from the second-to-last, otherwise from a random level; the second molecule of each pair mirrors the draw (`r → 100 − r`). Exhausted levels are dropped.

With `strips_wrapper`: every molecule is a domain constant (the problem declares only levels), each disjunctive dummy action becomes two actions `dummy-strips-action-<i>` with a single `(available m)` precondition, and `goal1..goal<num_goals>` are declared even when fewer goals are reachable; the problem then asks only for the reachable ones.

### Other
No action costs or metric. Domain requirements `:strips :disjunctive-preconditions :negative-preconditions :typing`. `make_task` returns `(domain, problem)`; the problem name is `pathways-r<R>-g<G>-l<L>`. Every goal molecule is relaxed reachable, but tasks can be unsolvable: associations consume their inputs and at most `num_substances` substances may be chosen (upstream: "the generator may produce unsolvable tasks"). If fewer than 2·`num_goals` goal molecules are reachable, `make_task` raises `ValueError` (upstream would print an undefined goal); `strips_wrapper` keeps the reachable goals like `wrapper.py`. Its domain has requirements `:strips :negative-preconditions :typing`, name `pathways-propositional`, and the problem is named `pathways-problem`.

## Comparison with reference tasks

Replaying the upstream C `rand()` with the IPC seeds through this port reproduces all 30 reference tasks exactly (objects, init facts and goal pairs); with Python's `random` the distribution is unchanged (mean reaction facts over 40 seeds, glibc vs Python RNG: p16 289 vs 291, p27 462 vs 473, p30 543 vs 547).

| aspect | reference tasks | this generator (mean of 10 seeds, same R/G/L) |
|---|---|---|
| reaction facts, p01 / p05 / p16 / p27 / p30 | 12 / 78 / 440 / 625 / 580 | 13.9 / 114.3 / 303.1 / 480.0 / 549.1 |
| `possible` substances, p01 / p05 / p16 / p27 / p30 | 16 / 22 / 55 / 71 / 58 | 8.7 / 29.7 / 47.9 / 60.9 / 65.2 |
| complex objects, p01 / p05 / p16 / p27 / p30 | 9 / 67 / 287 / 374 / 336 | 11.7 / 67.6 / 140.7 / 208.9 / 233.8 |
| goals / level objects | G / L+1 | G / L+1 |
| Autoscale optimal, `strips_wrapper` (30 tasks, 5 seeds, R = task's reaction count): goals used / reaction facts / `possible` | 7.77 / 73.1 / 20.3 | 7.74 / 84.3 / 24.5 |

**Deviations:**
- The IPC seeds are not typical draws of the generator: for large tasks the IPC reaction counts lie at the 97.5th–100th percentile of 40 fresh seeds (p16, p17, p19, p27), i.e. the IPC instances were apparently selected. The port follows the generator, not that selection.
- Goal constants are listed in database order; the IPC files list them in another (arbitrary) order.
- The IPC problem files had duplicate object declarations of goal molecules, removed by hand in the reference data; this port never declares constants as objects.
