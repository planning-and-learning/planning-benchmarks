# Misc generators

Our own variants of classical domains. They have no IPC or Autoscale reference
tasks, so their READMEs describe the distribution without a comparison.

| generator | based on |
|---|---|
| hiking_binary | `ipc/hiking`, with the ternary `partners` relation split into binary `partner_of` facts |
| transport_fuel | `ipc/transport`'s cost-free domain, with per-truck fuel and no refuelling |
